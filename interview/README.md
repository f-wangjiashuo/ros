## 快速备考建议 / Quick Preparation Tips

1. **通读知识图谱** (00_knowledge_map.md) — 建立课程全局观，理解培养目标与模块关系。  
   Read the knowledge map first to understand the overall program structure.

2. **重点课程优先** — 点云处理 → 摄影测量 → 遥感 → GIS编程 → 地统计学，这是与你研究兴趣最直接的5门课。  
   Prioritise: Point Cloud Processing → Photogrammetry → Remote Sensing → GIS Programming → Geostatistics.

3. **面试问答** (02_interview_qa.md) — 每题英文答案熟读，对应中文辅助理解，不必背诵，理解逻辑即可。  
   Read English answers thoroughly; use Chinese translations for understanding, not verbatim memorisation.

4. **研究方向** (03_research_alignment.md) — 提前想好：你的MSc论文想做什么？博士方向是什么？教授会问。  
   Think in advance about your MSc thesis idea and PhD direction — professors will ask.
