## 二、怎样在电脑或手机上阅读这些文件？

这些文件是 **Markdown 格式**（扩展名 `.md`），普通文本编辑器可以打开，但推荐以下方式阅读，效果更好：

### 方法一：GitHub 网页直接阅读（最简单，推荐📱电脑均可）

1. 打开浏览器，访问你的仓库：  
   `https://github.com/f-wangjiashuo/ros`
2. 点击 `interview` 文件夹
3. 点击任意 `.md` 文件，GitHub 会自动渲染成**格式漂亮的网页**，表格、代码块、标题都清晰可见
4. 手机上同样可以这样阅读

### 方法二：VS Code（电脑推荐，支持实时预览）

1. 用 VS Code 打开仓库文件夹
2. 打开任意 `.md` 文件
3. 按 `Ctrl+Shift+V`（Windows/Linux）或 `Cmd+Shift+V`（Mac）打开预览面板
4. 可以左右分屏，左边源码右边预览

### 方法三：Obsidian（最适合背诵和做笔记）

1. 下载免费软件 [Obsidian](https://obsidian.md/)
2. 将整个 `interview/` 文件夹作为 Vault（知识库）打开
3. Obsidian 支持双链笔记、图谱视图、闪卡背诵插件，非常适合这类学习材料
4. 可以在文件里直接做批注、高亮重点

### 方法四：手机 App 阅读

- **iOS**：`1Writer` 或 `Pretext`（免费）
- **Android**：`Markor`（免费）或 `Obsidian`（也有手机版）
- 或者直接用 **GitHub App** 手机浏览

## 四、背诵技巧（专为英文答案）

> 核心原则：**不要逐字背！背逻辑结构 + 关键词**

### 技巧1：三点法（最实用）

每道题把答案压缩成3个要点（3 key points）。例如 Q4（LiDAR原理）：

```
Point 1: 定义 — 主动遥感，飞行时间测距
Point 2: 组成 — 激光扫描仪 + IMU + GNSS
Point 3: 我的经历 — South Lidar Pro，地面滤波，输电线路检测
```

说答案时：先说Point 1，展开2-3句；再说Point 2；最后回到你的经历。

### 技巧2：关键词背诵（适合技术题）

在课程笔记里，每道技术题都有**公式和表格**。你不需要推导公式，但要能说出关键词。例如：

- 克里金 → 说出：变差函数、最优线性无偏估计（BLUE）、克里金方差（不确定性）
- 卡尔曼滤波 → 说出：预测步、更新步、过程噪声Q、测量噪声R、你的EKF实现

### 技巧3：自我录音

1. 手机打开录音
2. 对着题目用英文完整回答一遍（不看答案）
3. 播放录音，检查逻辑是否完整，发音是否清晰
4. 对照答案找差距
5. 重复2-3次直到顺畅

### 技巧4：对话练习（有朋友帮忙的话）

找同学或朋友扮演面试官，按照 `02_interview_qa.md` 里的题目顺序进行模拟面试。特别练习：
- Q1（自我介绍）：控制在2分钟以内
- Q13（LiDAR竞赛）：控制在3分钟以内，逻辑清晰
- Q11（论文选题）：流利说出研究问题

## 七、注意事项和常见问题

### ❓ 这些文件都是英文的，我英文不太好怎么办？

每个课程笔记文件有**中英双语对照**——英文是核心术语，中文是解释。课程笔记中每张表格都有中文列（比如"定义/Definition"列）。面试问答 `02_interview_qa.md` 里每段英文答案后面都跟着**中文翻译**。

**建议：** 先看中文理解意思，再反复读英文段落，最后只说英文。不要翻译腔，用简单清晰的英文表达比复杂句子更好。

### ❓ 公式这么多，需要推导吗？

**不需要！** 面试是口头考察，不会要求你在黑板上推导。你需要的是：
- 能说出公式的**名字**和**作用**（比如"最小二乘正规方程 $(A^TA)^{-1}A^Ty$"→"求最优估计值"）
- 能说清楚**你在哪个项目里用过它**（比如GNSS基线解算用了最小二乘，轨迹平滑用了EKF）
- 知道它的**局限性**（比如最小二乘假设误差正态分布，EKF线性化会引入截断误差）

### ❓ 课程笔记里的代码需要运行吗？

**不需要在面试前运行。** 代码是用来帮你理解工作流程的。但面试时提到"我会用Python + PDAL做点云处理流程"比"我会用ArcGIS"显得更有主动学习能力，印象更好。

### ❓ 内容太多了，记不住怎么办？

**只需要掌握两件事：**
1. **你自己的两个项目**（LiDAR竞赛 + GNSS项目）能流利用英文讲清楚 → Q13/Q14
2. **你的研究方向和论文想法**能流利表达 → Q11/Q12

其他技术问题（Q4-Q10）是加分项，答不全也没关系，但要有基本思路，不能完全不知道。

### ❓ 面试会问匈牙利语吗？

不会。德布勒森大学地理信息科学硕士是全英文授课项目（English-taught programme），面试用英文进行。可以提前学几句简单的匈牙利语问候（如 "Jó reggelt kívánok！"= Good morning），教授会对你的用心印象深刻，但不是必须的。
