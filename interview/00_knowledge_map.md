# 知识图谱：德布勒森大学地理信息科学硕士
# Knowledge Map – University of Debrecen Geoinformatics MSc

---

## 1. 培养目标总览 / Program Learning Outcomes

The Geoinformatics MSc produces graduates who can:

| # | Learning Outcome | 培养目标 |
|---|---|---|
| LO-1 | Apply advanced geospatial data collection techniques (LiDAR, GNSS, UAV, RS) | 掌握先进地理空间数据采集技术 |
| LO-2 | Process, analyse and model spatial data using GIS and statistical tools | 运用GIS与统计工具处理、分析、建模空间数据 |
| LO-3 | Develop and apply remote sensing methods (multispectral/hyperspectral/point cloud) | 开发并应用遥感方法 |
| LO-4 | Design and manage geodatabases; apply data governance and security principles | 设计管理地理数据库；应用数据治理与安全原则 |
| LO-5 | Create web-based maps, geovisualisations and interactive spatial applications | 创建网络地图与交互式地理可视化 |
| LO-6 | Programme GIS workflows; integrate open-source and commercial tools | 编写GIS工作流程；整合开源与商业工具 |
| LO-7 | Lead projects, manage stakeholders, and work within legal/ethical frameworks | 领导项目、管理利益相关者，遵守法律/伦理框架 |
| LO-8 | Conduct independent research and produce a scientific thesis | 开展独立研究并撰写科学论文 |

```
            │
            ├── 开发实现层  Development Layer

            └── 应用场景层  Application Layer
                ├── Environmental Informatics (环境监测)
                ├── Applied GIS in Regional Dev (城市/规划)
                └── Applied Agriculture Informatics (精准农业)
```

## 5. 核心技能链 / Core Competency Chain

```
传感器原理          数据处理               空间分析            AI决策
Sensor Physics  →  Data Processing  →  Spatial Analysis  →  AI/ML Decision
     │                  │                    │                    │
  LiDAR/IMU         Filtering/           Segmentation/        Deep Learning
  GNSS/UAV          Registration         Classification       Point Cloud
  Photogrammetry     DEM/DSM             Pattern Mining       Semantic 3D
```

> 这条技能链横跨了德布勒森MSc的几乎所有模块，说明该项目是实现您研究兴趣的理想平台。  
> This competency chain spans nearly all modules of the Debrecen MSc, confirming that the programme is an ideal platform to pursue your research interest.
